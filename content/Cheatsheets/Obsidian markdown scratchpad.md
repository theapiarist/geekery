Here's a comprehensive list of [Obsidian flavoured markdown examples](https://desktopcommander.app/blog/obsidian-markdown-cheatsheet-every-syntax-you-actually-need/).

The rest of this page is a scratchpad to test which work, or do not work, with Quartz. So, in no particular order … 

### Footnotes

I'll start with an inline footnote^[Which is a convenient way to do things]. But this doesn't work in Quartz. So, let's try and standard format footnote instead [^2]. 

And remember, for #ghost footnotes can be post-processed as described in [[Obsidian and Ghost and footnotes]].

### Comments

Flank text with double percent signs and it disappears … like this `%% Here is a comment %%` on the next line.

%% Here is a comment %%

### Callouts

> [!warning]
> And here is on Obsidian flavoured warning callout.

You can also add custom title text to these:

> [!warning] Yikes
